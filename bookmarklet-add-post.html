📱 Noteworthy News - Quick Add Post Bookmarklet

This bookmarklet lets you instantly add any X/Twitter post to your website with one click!

📌 Quick Setup:

Step 1: Drag the button below to your browser's bookmarks bar
Step 2: Visit any tweet on X/Twitter
Step 3: Click the bookmarklet in your bookmarks bar
Done! The post will be added automatically
➕ Add to Noteworthy

💡 Tip: Drag this button to your bookmarks bar, then click it on any tweet page to add it instantly!

🎯 How It Works:

  1. The bookmarklet extracts the tweet ID from the current page URL
  2. It sends the tweet URL to your Netlify function
  3. The function fetches the tweet data and stores it
  4. Refresh your website to see the new post!

⚡ For Automatic Posts (Best Solution):

For truly automatic posts, set up the X Webhook system. See SETUP_AUTO_POSTS.md for complete instructions.

The webhook will automatically add every new tweet you post, with no manual action needed!

📋 Alternative Methods:

  • Command Line: node scripts/quick-add-post.js <tweet-url>
  • Browser Console: See SETUP_AUTO_POSTS.md for scripts
  • X Webhook: Fully automatic (recommended)
