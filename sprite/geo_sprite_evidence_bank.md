# Geo-SPRITE Evidence Bank for AP European History

A comprehensive evidence bank organized by analytical lens and priority tier. Each item is tagged with its AP unit, region, best essay use, best prompt type, and a misuse warning.

**How to use this bank:**
- Tier 1 evidence should be automatic recall. These are the items graders expect to see.
- Tier 2 evidence elevates an essay from competent to strong. Deploy these for specificity.
- Tier 3 evidence signals mastery and earns complexity points. Use selectively, not exhaustively.

---

## Quick Reference: How to Deploy Evidence by Essay Type

**Causation essays:** Lead with Tier 1 context, support with Tier 1-2 evidence, earn complexity with a Tier 3 counterargument or long-term consequence.

**Comparison essays:** Pair evidence across categories. Use the same lens (e.g., Political) for both sides, then shift lenses for complexity.

**CCOT essays:** Tier 1 for the obvious changes, Tier 2 for what actually continued, Tier 3 for a nuance that complicates the narrative.

**Complexity point:** One well-deployed Tier 3 item that genuinely complicates the argument is worth more than three that merely add detail.
