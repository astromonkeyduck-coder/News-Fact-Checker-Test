# Konscious

Standalone, clean version of the Substack export for Konscious.

## Run locally
- Open `index.html` directly in a browser.

## Edit content
- Main page content lives in `index.html`.
- Styles live in `css/styles.css`.
- Images live in `assets/images/`.

## Add a new post
1. Add the new cover image to `assets/images/`.
2. Copy a post card in the `#writing` section of `index.html`.
3. Update the title, date, and excerpt text.
