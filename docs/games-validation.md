# Waterline Files validation and reproducible case paths

This document separates automated numerical checks from observed browser behavior. The world, sources and observations are fictional. A 100-point educational rubric result does not establish a real-world cause or forecast.

## Automated checks completed

`node --test tests/games/physics*.test.js tests/games/gis*.test.js tests/games/investigation*.test.js tests/games/season-physics.test.js` passed 55 tests in the isolated release workspace. The six season tests use actual 3600-second simulations, serialize/restore the numerical state, recompute GIS pins and grade saved comparisons against fixed masked observations. They also test meaningful rejected conclusions. Numerical convergence and budget tolerances are in [games-model.md](games-model.md).

All comparisons below require saving both runs at 60:00, pinning the comparison in the notebook and selecting the matching graph variable. Each final briefing selects exactly three records: the named source document, the computed spatial pin and the one-factor comparison. Select the indicated interpretation and at least one of that case's relevant uncertainty statements. Leave original observations fixed when experimenting.

## Reproducible paths through all six cases

1. **The map everyone shared:** save Maintained drainage and Restricted Old Town drain, then compare Old Town depth. Also save Less permeable North Works as the competing hypothesis. Compute North Works–Old Town distance. Reveal North Works depth at 2400 s, select the observation register, the distance pin and the drainage comparison. Choose the drainage-supported conclusion and the interpretation that the withheld reading favors a tested prediction. The initial Old Town 3600 s reading fits both restricted drainage and sealed Works within 0.001 m; the North Works reading distinguishes them. East Wharf does not justify the stronger conclusion. Alternatively, use the mechanism-not-unique conclusion with the sensitivity-only interpretation and retain the uncertainty.

2. **The missing connection:** save Maintained drainage and Unmapped Works–Wharf link. Select concentration and compare East Wharf. With the optional connection enabled, compute the directed North Works→East Wharf network path; its output must include `works-wharf`. Select the network inventory, path pin and comparison. Choose the link-supported conclusion, the interpretation that selected readings favor a tested prediction, and retain installation/model uncertainty. The fixed East Wharf 2400 s observation matches the link model; the unchanged network does not. A new measurement is optional for this conclusion.

3. **The perfect match:** save Lighter rain, restricted drain (55 mm/h, 0.05 m³/s) and Heavier rain, open drain (75 mm/h, 0.45 m³/s). They both fit the initial Old Town final depth within 0.001 m. For a separate controlled experiment, load the lighter-rain preset and change only rainfall to 75 mm/h, preserving the restricted drain; save and compare this with the original lighter-rain run. Compute Old Town–East Wharf distance. Select the register, distance pin and one-factor rainfall comparison. The non-identified conclusion plus sensitivity-only interpretation earns full credit while withholding the extra reading. Revealing East Wharf final depth supports the lighter-rain hypothesis with the discriminating-measurement interpretation. North Works final depth does not discriminate at this tolerance.

4. **The fix that moved the problem:** save Maintained drainage and Expanded Old Town drain at the same storm and duration. Compare depth at both Old Town and Reed Marsh; compute the directed Old Town→Reed Marsh path. Select the network document, path pin and comparison. Choose the tradeoff conclusion with the bounded sensitivity interpretation and relevant impact limitations. Actual saved peaks decrease at Old Town and increase at Reed Marsh. One location's improvement does not imply universal improvement.

5. **Out of time:** save Maintained drainage (tracer release 600 s) and Later tracer release (1200 s). Select concentration and compare Old Town. Keep source North Works, mass 600 g, all water inputs and network identical. Compute the directed North Works→Old Town path. Select the common-clock register, path pin and comparison. Choose the timing-supported conclusion and the interpretation that selected readings favor a tested prediction. The fixed Old Town 1800 s reading distinguishes these schedules: approximately 0.586743 g/m³ for the later release versus 0.001201 g/m³ for the earlier release. The water solution is unchanged. Do not interpret this as measured pipe velocity.

6. **The Waterline briefing:** load Upstream retention and permeable surface. Save its full-hour prediction (Works permeability 48 mm/h, retained lowering 0.10 m). Change only permeability to 28 mm/h while retaining the lowered parcel; run for the same hour and save. Compare depth at Old Town and Reed Marsh. Restore the original 48 mm/h retention run, then compute a North Works–Old Town terrain profile and the three rainfall variants 52,65,78 mm/h. Select the design-sheet source, profile pin and one-factor permeability comparison. Choose either the limited-further-trial or defer conclusion with sensitivity-only interpretation and relevant limitations. The actual retained-parcel rainfall envelope is required for either conclusion. Baseline versus retention changes two parameters and cannot substitute for the isolated permeability experiment.
